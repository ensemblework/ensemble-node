CONNECTOR LOGOS

These local identification assets are reused from ensemblework/ensemble,
apps/hub-web/components/connectors/brands. manifest.json records each asset's
name, source and original fit. The source library is available at:
https://github.com/ensemblework/ensemble/tree/c3c315d/apps/hub-web/components/connectors/brands

The Wispr Flow placeholder was replaced with
the vendor's own apple-touch icon (resized to 96 px); Zotero was replaced with
the CC0 Simple Icons mark, coloured #CC2936. No runtime vendor requests are made.
Jam's SVG has an explicit viewBox added for reliable scaling.

used only to identify services. Ensemble is not affiliated with or endorsed
by them. Copyright licences do not grant trademark rights.
